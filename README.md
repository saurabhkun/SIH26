## 🏛️ Official Problem Statement & Engineering Notice

CivicResolve is built specifically for **Smart India Hackathon 2026 (Problem Statement ID: 26043)** under the aegis of the **Government of Jharkhand**.

It addresses the fundamental systemic bottleneck in state administration: grassroots citizen issues often disappear into bureaucratic black holes, while premier state universities possess untapped R&D infrastructure, and corporate entities seek transparent, high-impact CSR allocation channels. 

CivicResolve bridges these disparate silos into a single, closed-loop state innovation operating system across all **24 Administrative Districts of Jharkhand** (covering Palamu, North Chotanagpur, South Chotanagpur, Kolhan, and Santhal Pargana divisions).

## ⚡ The Problem & The Solution

### The Broken Status Quo
1. **The Civic Grievance Black Hole:** Routine potholes are lumped together with critical environmental toxins and structural dam failures in legacy CRM portals, resulting in identical slow response times.
2. **Untapped Academic R&D Infrastructure:** Millions of INR worth of sophisticated laboratory equipment across institutions like BIT Mesra, IIT ISM Dhanbad, and NIT Jamshedpur sits idle from civic application.
3. **CSR Capital Fragmentation:** Corporate CSR wings (Tata Steel, Coal India, NTPC) struggle with opaque fund utilization and lack of verifiable project milestones.
4. **Single Point of Failure in Public Tenders:** When a primary academic contractor stalls or drops out, the entire project collapses with no automated failover or contingency escalation.

### The Solution: 5-Track Closed-Loop State Machine
* **Circuit-Breaker Triage:** Instant separation of natural hazards, municipal repairs, and deep R&D problems.
* **Consortium-Driven Academic Bidding:** Matchmaking state problems with institution laboratory capability tags across Tier L1, L2, L3R, and L3G.
* **Milestone Escrow & CSR Co-Funding:** Funds are locked in smart escrow and disbursed only upon verified physical milestone completion.
* **Automated Failover & Custody Cascade:** Pre-selected 1 Winner + 2 Designated Runners-Up ensure 0-downtime execution if a lead institution drops out.

## 🚀 Key Innovations & Engineering Architecture

### 1. ⚡ Multi-Track Intake & Circuit Breaker Pattern
* **Track A (`DISASTER_FAST_TRACK`):** If hazard severity index $\ge 85$ or critical signatures (e.g., *bridge collapse, toxic effluent, mine cave-in, flash flood*) are detected, the system trips the academic circuit breaker. The issue bypasses the R&D queue entirely and routes immediately to the **District Magistrate & Disaster Response Cell**.
* **Track B (`TRADITIONAL_GOVT_GRIEVANCE`):** Routine low-severity maintenance tasks (e.g., *potholes, streetlights, garbage clearance*) are dispatched to Municipal Urban Local Bodies (ULBs).
* **Track C (`RO_INNOVATION_PIPELINE`):** High-impact systemic problems (e.g., *groundwater fluoride filtration, solar micro-grid telemetry, agricultural bio-sensors*) enter the competitive university innovation bidding pipeline.

### 2. 🤖 4-Factor AI Proposal Pre-Scoring Matrix
Incoming institutional bids are evaluated against an empirical multi-objective scoring formula:

$$\text{Composite Score} = S_{\text{Feasibility}} (30) + S_{\text{LabMatch}} (30) + S_{\text{TrackRecord}} (20) + S_{\text{Novelty}} (20)$$

* **Feasibility ($0–30\text{ pts}$):** Evaluates methodology realism, timeline milestones, and projected cost efficiency.
* **Lab Infrastructure Match ($0–30\text{ pts}$):** Matches declared institutional lab equipment tags against the problem domain requirements.
* **Past Track Record ($0–20\text{ pts}$):** Historical institutional completion rate and nodal audit scores.
* **Novelty & Impact ($0–20\text{ pts}$):** Patent potential, local resource utilization, and grassroots scalability.

### 3. ⚖️ Human Decision Panel & Automated Failover Cascading
* AI serves as a decision-support copilot, generating an unbiased pre-scored shortlist.
* The **State Nodal Officer & Domain Expert Panel** officially designates **1 Winner + 2 Backup Runners-Up**.
* **Automatic Failover:** If the primary lead drops out or breaches milestone delivery SLAs, custody cascades seamlessly to **Runner-Up #1** without resetting the public tender or causing timeline stalls.

### 4. 🪜 5-Stage Contingency Escalation Ladder
To prevent institutional deadlock, CivicResolve enforces an automated 5-stage escalation state machine:
* **Stage 1 (Initial Broadcast):** Broadcast to Tier L1 institutions for an initial bidding window.
* **Stage 2 (Window Evaluation):** Nodal panel reviews received bids.
* **Stage 3 (Widened Spectrum + Sweeteners):** If zero bids are placed, eligibility broadens to **L1 + L2** with attached state sweeteners (+15 Bonus Accreditation Points, Fast-Track CSR Funding).
* **Stage 4 (Domain Expert Direct Nomination):** State Domain Expert directly nominates a specialized institution with mandatory Accept/Decline consent loop.
* **Stage 5 (Govt Public Works Egress):** If declined, project exits the academic pipeline and transfers directly to Public Works for standard departmental civil execution.

### 5. 🔬 Hierarchical Institutional Subcontracting (L1/L2 ➔ L3)
Recognizing that premier state universities (L1/L2) are often located far from rural execution sites, CivicResolve supports structured delegation:
* **L3R (Research-Capable Local):** Local polytechnics and district colleges handle water/soil sample testing, chemical assays, and local sensor calibration.
* **L3G (Ground-Level Execution):** Local ITIs and community colleges manage physical site surveys, hardware deployment, and local stakeholder coordination.

### 6. 🗺️ High-Performance SVG Jharkhand Geographic Choropleth Map Engine
* **SVG Stacking Order Fix (Anti-Sinking):** In SVG 1.1, elements render in DOM sequence without CSS `z-index`. When hovering a district, the element is dynamically appended to its parent `<g>` node via `e.currentTarget.parentNode.appendChild(e.currentTarget)`, guaranteeing boundary stroke visibility without clipped edges.
* **Hardware-Accelerated Elevation:** Pop-up transform via GPU-accelerated CSS (`transform-box: fill-box`, `scale(1.025)`, `filter: drop-shadow(...)`).
* **Zero Frame Loops:** Coordinate grids and D3 geo-paths are strictly memoized via `useMemo` for 60 FPS rendering on low-end civic hardware.

### 7. 🔒 Cryptographic Session Security & Role-Based Portals
* **HMAC-SHA256 Session Shield:** Tamper-proof session tokens signed with state secret keys (`lib/auth/session.ts`).
* **Bcrypt Password Protection:** Enterprise-grade salted hashing for newly registered institutional and corporate entities.
* **Multi-Portal Architecture:**
  - 🏛️ **Government Nodal Portal** (`/dashboard/gov`) — Live triage, AI evaluation matrix, allocations, CSR overview.
  - 🎓 **University / College Portal** (`/dashboard/college`) — Challenge marketplace, proposal submission, milestone tracker.
  - 🏭 **Industry / CSR Partner Portal** (`/dashboard/industry`) — Curated R&D feeds, CSR portfolio tracker, milestone fund escrow release.

## ⚙️ Quick Start & Execution

### Prerequisites
- **Node.js**: v18.0+ or v20.0+
- **MongoDB**: Local MongoDB daemon or MongoDB Atlas URI *(automatic in-memory fallback enabled if offline)*

### 1. Clone & Install Dependencies
```bash
git clone https://github.com/saurabhkun/SIH26.git
cd SIH26
npm install
```

### 2. Environment Configuration
Create a `.env.local` file in the root directory:
```env
MONGODB_URI=mongodb://127.0.0.1:27017/civicresolve
SESSION_SECRET=civicresolve_super_secret_hmac_key_2026
```
*(If a local MongoDB daemon is not detected, CivicResolve automatically spins up an embedded in-memory database).*

### 3. Seed Database with Realistic State Data
```bash
npm run seed
```

```

### 5. Launch Development Server

```
Open [http://localhost:3000](http://localhost:3000) in your browser.
